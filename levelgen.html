📋 How to add your levels to the game

  1. Press Create, then in the save dialog choose the levels/ folder as the destination — every level file must live inside the Levels folder of this project (next to riverbend.json).
  2. Once your files are in levels/, run build_levels.bat from the Tools folder (double-click it, or run it from a terminal) to rebuild the level list. The new levels will then appear in the game's level select.
  3. If you saved somewhere else, move the downloaded .json files into levels/ first, then run the build.
